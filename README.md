# Santa's Last Stand

A Christmas adventure about Santa racing to save Christmas from a conspiracy of his greatest enemies. Each chapter is a different kind of game: platformer, brawler, strategy, stealth, racing, RPG, detective, shooter and a 3D sleigh flyer.

**Play in your browser:** https://smcode-source.github.io/santas-last-stand/

Built with [Godot 4](https://godotengine.org) (GDScript, Compatibility renderer) and exported to the web. Every push to `main` is built and deployed to GitHub Pages by `.github/workflows/deploy.yml`.

## Running locally
1. Install the Godot 4.7 editor.
2. Open `project.godot` in Godot and press F5.
